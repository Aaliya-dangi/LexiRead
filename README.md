LexiRead 📚

An Accessible Reading Assistant

LexiRead is a reading support web application designed to help people with dyslexia and reading difficulties understand text more comfortably through simplified text, visual learning, audio support, and interactive comprehension activities.

🌟 About the Project

LexiRead aims to make digital reading more accessible and engaging. It combines reading assistance, visual representations, text-to-speech, and comprehension activities in one application to support different learning needs.

✨ Key Features

- Text Simplification: Makes difficult passages easier to understand.
- Reading-Friendly Display: Offers accessible fonts, themes, and reading settings.
- Text-to-Speech: Lets users listen to reading content.
- Visual Understanding: Presents passage information through visual representations.
- Passage-Based Process Diagrams: Uses illustrations, concise labels, and horizontal arrows to explain processes.
- Understanding Check: Provides interactive questions based on the active passage.
- Pronunciation Practice: Helps users practise word pronunciation.
- Document Support: Supports uploaded reading material, including PDF-based workflows.
